# Solution
```sql
-- Select the facility ID and facility name
SELECT
    facilities.facid,
    facilities.name,

    -- Calculate total cost:
    -- Each slot costs 0.5
    -- SUM() adds the cost of all bookings for the facility
    -- ROUND(..., 2) rounds the result to 2 decimal places
    ROUND(
        SUM(bookings.slots * 0.5),
        2
    ) AS total

-- Start with the bookings table
FROM cd.bookings AS bookings

-- Join bookings with facilities
-- so we can get the facility ID and name
JOIN cd.facilities AS facilities
    ON bookings.facid = facilities.facid

-- Create one group for each facility
-- This allows SUM() to calculate the total per facility
GROUP BY
    facilities.facid

-- Sort the results by facility ID
ORDER BY
    facilities.facid;
```

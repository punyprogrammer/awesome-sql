# Answer
```sql
UPDATE cd.facilities
SET
    membercost = 1.1 * (
        SELECT membercost
        FROM cd.facilities
        WHERE facid = 0
    ),
    guestcost = 1.1 * (
        SELECT guestcost
        FROM cd.facilities
        WHERE facid = 0
    )
WHERE facid = 1;
```

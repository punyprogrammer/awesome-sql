# Solution

```sql
-- Outer query:
-- Filter the already-calculated facility revenue
SELECT
    name,
    revenue

FROM (

    -- Inner query:
    -- Calculate total revenue for each facility
    SELECT
        facilities.name,

        SUM(
            CASE
                -- Guests pay guestcost
                WHEN bookings.memid = 0
                    THEN bookings.slots * facilities.guestcost

                -- Members pay membercost
                ELSE
                    bookings.slots * facilities.membercost
            END
        ) AS revenue

    FROM cd.bookings AS bookings

    -- Get facility pricing information
    JOIN cd.facilities AS facilities
        ON bookings.facid = facilities.facid

    -- Create one group per facility
    GROUP BY facilities.name

) AS facility_revenue

-- Now revenue behaves like a normal column
WHERE revenue < 1000

-- Sort by revenue
ORDER BY revenue;
```

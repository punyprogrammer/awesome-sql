# Solution

```sql
-- Get the facility, month, and total number of slots booked
SELECT
    facid,

    -- Extract the month from the booking date
    EXTRACT(MONTH FROM starttime) AS month,

    -- Add up all slots booked for each facility/month combination
    SUM(slots) AS total_slots

FROM cd.bookings

WHERE
    -- Only include bookings made during 2012
    EXTRACT(YEAR FROM starttime) = 2012

GROUP BY
    -- Create a group for each facility and month
    facid,
    EXTRACT(MONTH FROM starttime)

ORDER BY
    -- Sort first by facility, then by month
    facid,
    EXTRACT(MONTH FROM starttime);
```

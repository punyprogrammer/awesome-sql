# Solution
```sql
-- Select the member's first and last name
-- and the first and last name of their recommender
SELECT
    a.firstname AS memfname,
    a.surname AS memsname,
    b.firstname AS recfname,
    b.surname AS recsname

-- a represents the member
FROM cd.members a

-- b represents the recommender
-- LEFT JOIN ensures all members are included,
-- even if they don't have a recommender
LEFT JOIN cd.members b
    ON a.recommendedby = b.memid

-- Sort members by surname, then firstname
ORDER BY
    a.surname,
    a.firstname;s
```

# Solution
```sql
-- Select member details and their first booking after September 1, 2012
SELECT
    members.surname,
    members.firstname,
    members.memid,

    -- Find the earliest booking date/time for each member
    MIN(bookings.starttime) AS starttime

-- Start with the members table
FROM cd.members AS members

-- Join members with their bookings using memid
JOIN cd.bookings AS bookings
    ON members.memid = bookings.memid

-- Only consider bookings after September 1, 2012
WHERE bookings.starttime > '2012-09-01'

-- Create one group for each member
-- MIN() will then find the earliest booking for each member
GROUP BY
    members.memid

-- Sort the results by member ID
ORDER BY
    members.memid;
```

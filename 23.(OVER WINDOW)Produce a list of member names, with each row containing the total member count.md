# Solution


```
-- Select the total number of members,
-- along with each member's first and last name.
SELECT
    -- COUNT(*) counts all members.
    -- OVER() makes it a window function, so the total
    -- count is repeated on every row instead of grouping rows.
    COUNT(*) OVER () AS count,

    -- Member's first name
    firstname,

    -- Member's surname
    surname

FROM cd.members

-- Display members in the order they joined.
ORDER BY joindate;
```
